# Program

Program-level planning, milestones, and decision authority.

## Planned structure

```
program/
  roadmap.md          — phased development roadmap with go/no-go gates
  milestones.md       — milestone definitions and success criteria
  work-packages/      — decomposed work packages with scope and deliverables
  decisions/          — program-level architectural decisions (not ops ADRs)
```

Populated as the program matures. The first study (`studies/archive/lunar-humanoid-pathfinder/`) provides the initial roadmap inputs.
