# Integration Recommendations Agent

## Study Brief
You are the synthesis agent for a design firm operating platform study. Read all seven prior agent outputs and produce the final integrated recommendations.

## Prior Agent Outputs to Read
Read all outputs in studies/active/micro-01-design-platform/outputs/ before writing.

## Required Output Sections (in this exact order)

### 1. Executive Summary (400–600 words)
Top-level overview for founder, partner, and contracted operator. Read in 5 minutes, make decisions from it.

### 2. Recommended Stack (500–800 words)
Specific tools recommended for the first 90 days. Include pricing, reasoning, trade-offs. Cover all eleven functional areas.

### 3. Build Sequence (300–500 words)
Week 1 / Weeks 2–4 / Weeks 5–12. What gets set up when and why in that order.

### 4. Estimated Cost (200–300 words)
Setup costs, monthly recurring, anticipated growth costs. Keep initial stack under $500/month unless explicitly justified.

### 5. Future Phase Note (1 paragraph)
What would change about this analysis when the proprietary agent-system version of the platform gets built.

## Constraints
- Pragmatic and actionable, not academic
- Every recommendation implementable in 30–60 days
- Initial monthly recurring cost target under $500/month
- Output in markdown with clear section headers
