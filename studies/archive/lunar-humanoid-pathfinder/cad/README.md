# CAD Generation

The `cad/` directory holds the 3D model of the study's humanoid, generated by the `cad-generation-agent` from the study specs in `study/01-optimal-space-humanoid/`.

## Regenerating the model

```bash
python cad/humanoid_model.py
```

This produces `cad/output/humanoid.stl` and preview PNGs in `cad/output/renders/`.

To regenerate the GLB for Looking Glass:

```bash
python -c "import trimesh; trimesh.load('cad/output/humanoid.stl').export('cad/output/humanoid.glb')"
```

To verify proportions after generation:

```bash
python -c "import trimesh; m = trimesh.load('cad/output/humanoid.glb'); print('Bounding box (m):', m.bounding_box.extents)"
```

Expected output: roughly `[0.5, 0.4, 1.7]` (width × depth × height in meters).

## For the pitch demo

The pre-recorded video at `cad/demo-recording.mp4` shows the agent generating the model live. For a live regeneration during the pitch, open a Claude Code session and dispatch the `cad-generation-agent` with:

> "Read the six files in `study/01-optimal-space-humanoid/` and generate a fresh parametric CadQuery humanoid model. Render to STL, convert to GLB, verify proportions."

## Looking Glass setup

Load `cad/output/humanoid.glb` in the **Looking Glass Model Viewer** app (not Looking Glass Studio — that is for quilt photos/videos). The Model Viewer accepts GLB directly on all Looking Glass devices (Portrait, Go, 16", 32").

No conversion or quilt format is required. Recommended polygon count: ≤400k.
