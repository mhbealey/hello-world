# Lunar Humanoid Pathfinder — Archived Study

**Status:** Read-only reference. Do not modify.
**Archived:** 2026-05-04
**Final stage:** Stage 8

## What this was

A concept study examining humanoid-forward architecture for space exploration, with the lunar far side permanent base as the testbed. Structured around four questions: optimal space humanoid configuration, human-in-the-loop value, workflow/ConOps, and build-and-deploy program structure.

## Why archived

Superseded by the system v1.0 restructure, which reframes this repository as a private space program analytical infrastructure. This study becomes the first output of that system — proof-of-concept for the agent-driven study model.

## What's here

- `study/` — the full document tree across all sections
- `corpus/` — references.bib and heritage notes
- `cad/` — parametric CAD model and generation log
- `site/` — rendered HTML version of the study
- `review/` — all reviewer findings and triage documents
- `handbacks/` — stage handback documents (stages 1–8)
- `retro/` — session logs from the study execution
- `full-report.md` — compiled full document

## Reuse guidance

Agents working on new studies should treat this archive as a heritage source. The cross-coupling log, margins registry, and reviewer findings are valid prior art. The agent definitions that drove this study live in `system/agents/base/` (generified) and `system/agents/domain/lunar-surface/` (domain-specific).
