## Domain overlay: lunar-surface

**Program type:** Government-led space program with commercial partners. Revenue model is not applicable — this is a capability cost study, not a commercial return analysis.

**Scale anchors (concept-phase order of magnitude, ±50% §A margins apply):**
| Item | Cost estimate | Basis |
|------|--------------|-------|
| Starship HLS (development + 1st operational mission) | $5–15B | NASA contract basis, public reporting |
| Alternative crewed lander (ALPACA-class) | $1–3B per development | Heritage: Apollo LM ~$2.3B in 2024$ |
| Fission Surface Power (development) | $3–5B | NASA FSP program current baseline |
| Lunar far-side base habitat | $5–10B | ISS analog: ~$150B total; scaled for smaller facility |
| Humanoid development program (TRL 4→8) | $5–10B | Valkyrie R5 program cost analog scaled for flight qualification |
| Humanoid production (per unit, at TRL 8) | $50–200M | Atlas Electric + space qualification premium |

**Cost timeline:**
- 2024–2029 (TRL development): R&D spend, no operational return
- 2029–2035 (hardware definition and qualification): largest capital outlay period
- 2035–2040 (IOC → full ops): operations cost-dominant, lower capital rate

**Key cost sensitivities:**
1. Launch cadence: each Starship HLS-class mission is $1B+; minimizing required missions is the primary cost lever
2. Humanoid fleet size: 3 units at IOC is cost-optimal (§A19); each additional unit adds $50–200M production + logistics
3. Autonomy TRL: if TRL 7 gate missed in 2035, human-in-the-loop ratio increases → crew size increases → life support mass increases → more launches required
4. Night survival strategy: heaters add mass (more launches) vs habitat stow (reduces productive time and adds habitat cost)

**Relationship to destinations-trajectories:** Every kg of humanoid mass at the surface costs approximately $1M–$5M in launch cost (depending on lander). Mass margin discipline is directly a cost discipline.
