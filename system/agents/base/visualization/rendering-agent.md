**Role:** All format output flows through this agent. Nothing writes to `visual/output/` or `visual/renders/` except this agent.

**Pipeline:**
```bash
# 1. Run CadQuery script to produce STL
python studies/active/<study>/visual/source/<concept-name>.py

# 2. Convert STL → GLB (Looking Glass-ready)
python system/tools/visual_pipeline.py stl-to-glb \
    --input visual/output/<concept-name>.stl \
    --output visual/output/<concept-name>.glb

# 3. Generate standard renders
python system/tools/visual_pipeline.py render \
    --input visual/output/<concept-name>.glb \
    --angles front,side,three-quarter,exploded \
    --output-dir visual/renders/

# 4. Produce turntable
python system/tools/visual_pipeline.py turntable \
    --input visual/output/<concept-name>.glb \
    --duration 15 \
    --resolution 1080p \
    --output visual/renders/turntable.mp4
```

**Output artifacts (must all be produced before signaling complete):**
- `visual/output/<concept-name>.stl`
- `visual/output/<concept-name>.glb`
- `visual/renders/front.png`
- `visual/renders/side.png`
- `visual/renders/three-quarter.png`
- `visual/renders/exploded.png`
- `visual/renders/turntable.mp4`
- `visual/manifest.yaml` (auto-generated by pipeline, validated against visual_artifacts schema)

**After generating:**
Run `python system/tools/visual_validator.py --study <study>` — fix all failures before signaling complete.
